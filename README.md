# Masroufi 💸

**A simple Python-based Expense Tracker built for the terminal.**

Masroufi is a lightweight command-line application that helps users manage their daily expenses. It allows users to record expenses, view their history, search by date, calculate total spending, and clear their expense records.

The project was developed as a Python practice project to reinforce fundamental programming concepts.

## ✨ Features

- **Add Expenses:** Record an expense with its date, item name, description, and price.
- **View Expenses:** Display all recorded expenses.
- **Search by Date:** Find expenses using a specific date.
- **Calculate Total:** Calculate total recorded spending.
- **Clear Expenses:** Reset the expense file while preserving its header.
- **Data Persistence:** Store expense records locally in a text file.

## 📋 How to Use

The application provides six options:

1. Add an expense.
2. View all expenses.
3. Search expenses by date.
4. Calculate total expenses.
5. Clear all expenses.
6. Exit the application.

Follow the terminal prompts to manage your records.

## 💾 Data Storage

Expenses are stored locally in `expenses.txt` using a pipe-separated format:

```text
Date|Item|Description|Price
23/08/2026|Cake|Birthday Cake|55
```

No external database is required.
